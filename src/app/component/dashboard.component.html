Projects Overview

Java Performance Engineering
This repository documents a logscanner engineering journey in Java. Starting from the most natural, readable solution and improving it step by step. each version isolates one bottleneck, fixes it, measures the result, and explains why it worked. The goal is not just to arrive at a fast solution. It is to understand why the naive solution is slow, and what exactly each change does to the hardware and the JVM.

ApiDoc CLI Tool
ApiDoc is a standalone CLI tool for generating API documentation from Java and Spring Boot projects using static AST analysis. It scans Controllers and DTOs marked with custom annotations and builds structured Markdown documentation without running the application or loading the Spring context. The tool supports multi-module Maven projects and microservice architectures, enabling full type resolution across shared libraries and services.
